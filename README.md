# ぷちのきせかえ

里親さんが、うちに来るぷちの「なまえ・いろ・め・くち・おやすみのかお・メガネ」を選ぶページ。
選んだ内容は LINE に貼る文とリンク(URL の # 以降に状態が入る)になる。声はお届けの日に決める。

- 公開: https://teampuchi.github.io/kisekae/
- 1ファイル(index.html)。ビルド無し。GitHub Pages(main / root)
- 目・口・おやすみの部品と動きは m5-petit-firmware の drawFace() と同じ寸法(鼻は固定)
- 里親さんの個人情報は置かない。名前は URL とその端末のブラウザにだけ残る

チームぷち(横地・山田)

## 運用(版・リリース)

- 版は `index.html` の 2 か所: `<meta name="version" content="1.0.0">` と `const KISEKAE_VERSION = "1.0.0"`。**上げるときは両方を同じに**(違うと CI が止まる)
- ページの下に「ぷちのきせかえ v1.0.0」と出る。きせかえの URL(`#` 以降)にも `v=1.0.0` が入るので、里親さんが貼ってくれた文を見れば、どの版で決めた顔か分かる
- **main に入ると、CI が同じ名前のタグ(`v1.0.0`)と Release を作る**(`.github/workflows/release.yml`)。版を変えない push ではタグは増えない
- 版の上げ方の目安: 顔の部品や寸法が変わった(ファームの drawFace() に合わせた)= 真ん中の数字、文言や色だけ = 末尾の数字
- 版の履歴: v1.1.1 = 2026-10-11(背景を しろ・きなり・くりーむ の 3 色に。こん・くろ はやめた)/ v1.1.0 = 2026-10-11(たまご・ラベンダー・みずいろ を外して もも・ぶどう・あお に。選んだ色に名前(`cn=`)。背景を 5 色から(`b=`、ファームの設定ページと同じ)。既定の色は わかたけ)/ v1.0.0 = 2026-10-10(9/14 公開〜9/24 までの形。目 6 種・口 4 種・おやすみ 3 種・メガネ、times 用のアイコン)
